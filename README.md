# RoohuCode

Get your APK (no computer needed, only a free GitHub account):

1. Make a new GitHub repository.
2. Upload ALL files from this folder (keep the folders).
   Important: the `.github` folder must be uploaded too.
3. Open the repository, tap Actions, tap "Build RoohuCode APK", tap Run workflow.
4. Wait about 5 minutes. Open the finished run, download "RoohuCode-apk".
5. Unzip it, install app-debug.apk on your phone.
   (Allow "Install unknown apps" when the phone asks.)

You can send this APK to anyone.
